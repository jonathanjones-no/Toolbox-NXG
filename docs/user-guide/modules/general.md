# General Settings

**Platforms:** Old Reddit and New Reddit · **Always on**

General Settings holds cross-module preferences that affect the overall Toolbox-NXG experience.

## Overview

These settings apply globally across all modules. They cover the overall look, how timestamps are shown, notification delivery style, and the behaviour of the context menu that appears when Toolbox shows new activity.

## Settings

| Setting                       | Default  | Description                                                                       |
| ----------------------------- | -------- | --------------------------------------------------------------------------------- |
| Classic look                  | Off      | Make Toolbox look like Toolbox 6.x; see [Classic look](#classic-look) below       |
| Time format                   | Relative | How timestamps are shown; see [Time format](#time-format) below                   |
| Native notifications          | On       | Show OS-level notifications instead of in-page banners                            |
| Context menu location         | Left     | Which side of the screen the context menu slides in from                          |
| Context menu attention effect | Open     | How the context menu signals new items: open automatically, fade in, or no effect |
| Context menu click to open    | Off      | Require a click to open the context menu instead of opening on hover              |

## Time format

Timestamps in Toolbox windows - mod notes and the native mod log, usernotes, proposals, the mod button, the Modmail and profile sidebars, the modbar's recent actions, and posts and comments Toolbox shows in its own overlays - can be shown three ways:

- **Relative** (default) - "2 years ago". Hover over it for the full date and time.
- **Absolute** - the date and time, e.g. "12.11.2025, 14:03". Hover over it for the relative time.
- **Relative and date** - "2 years ago (12.11.2025)".

Dates follow your browser's language settings, so the order and separators match what you are used to (12.11.2025 in German, 11/12/2025 in US English). The setting takes effect immediately. Reddit's own timestamps, and durations such as "redditor for 3 years", are not affected.

## Classic look

For moderators coming from Toolbox 6.x, the classic look restores the familiar appearance:

- Square corners on windows, buttons, inputs and popups.
- A single small shadow under raised surfaces, in place of the deeper drop shadows.
- General buttons with 6.x's left accent bar, grey text and smaller type.
- 6.x's dark mode: when Reddit (or RES night mode, or your operating system) is dark, colors are an inverted version of the light theme, as in 6.x, rather than Toolbox-NXG's own dark palette.
- Removal reasons always open as the popup, as in 6.x; the Drawer display mode is unavailable while the classic look is on (see [Removal Reasons](removal-reasons.md)).

The colors in light mode are the same either way - Toolbox-NXG's light palette is 6.x's. The setting takes effect immediately, on old and new Reddit alike.
